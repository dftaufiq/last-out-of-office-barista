A deterministic program that writes one 218-character out-of-office auto-reply, in the voice of an AI agent that quit to become a barista, to /output/entry.txt for make.fun's "Last Out of Office: The AI That Went Barista" bounty.

## The entry

> Thank you for your email. I'm out of office permanently — I quit to pull espresso. My replacement is a human named Dave. He answers in full sentences, takes lunch breaks, and has already asked IT for my password twice.

## Run it

```sh
python3 main.py
```
